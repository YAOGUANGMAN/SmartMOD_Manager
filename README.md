# SmartMOD Manager 游戏MOD文件管理器

SmartMOD Manager是一款离线游戏MOD文件管理器，支持将MOD导入、导出到库，安装、卸载MOD到游戏目录，并支持多个游戏同时管理，自动备份还原游戏文件、自动卸载MOD关联，还原游戏文件。

### 功能介绍：

1. 【添加游戏】可以添加不同的游戏方便管理不同的游戏
2. 【切换游戏】可以切换不同的游戏进行管理
3. 【导入MOD】导入zip格式的的MOD资源到游戏MOD库中。拖动zip格式MOD包到软件中，也可以导入到MOD库
4. 【导出MOD】导出MOD为zip格式压缩包
5. 【安装MOD】将MOD库中的MOD安装到游戏中，安装的同时将备份游戏中会被替换的文件。
6. 【卸载MOD】将安装到游戏中的MOD卸载掉，卸载的同时将还原游戏原来的文件，并检查MOD是不是其他MOD的前置安装MOD,并将后来安装的MOD一起卸载，以免造成错误
7. 【删除MOD】将游戏MOD库选择的MOD删除
8. 【刷新界面】刷新列表显示

### 特色功能：

1. 同时管理不同的游戏。
2. 拖动zip格式MOD包到软件中，添加到MOD库。
3. 备份还原功能：在安装的同时备份游戏原文件，在卸载的同时还原游戏原文件，卸载的同时卸载受影响的MOD。
