# SmartMOD_Manager
离线游戏MOD文件管理器，支持MOD导入、导出到库，安装、卸载MOD到游戏目录，并支持多个游戏管理，自动备份还原游戏文件、自动卸载MOD关联，还原游戏文件。Offline game mod manager, supporting mod import and export to the library, mod installation and uninstallation in game directories, multi-game management, automatic backup and restoration of game files, and automatic removal of mod associations.
